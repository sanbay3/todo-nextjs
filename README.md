# ToDo App

## 概要

Next.js（App Router）で作ったシンプルなToDoアプリです。
タスクの追加・完了切り替え・削除ができ、入力したタスクはブラウザのlocalStorageに保存されるため、ページを再読み込みしても消えません。

## 機能

- タスクの追加・削除
- タスクの完了 / 未完了の切り替え
- フィルター表示（すべて / 未完了 / 完了）
- localStorageによるデータ永続化（ページ更新後も保持）
- モバイル対応のレスポンシブデザイン

## 使用技術

- Next.js（App Router）
- React（useState / useEffect）
- JavaScript（TypeScriptは未使用）
- Tailwind CSS
